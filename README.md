# PyCards

Десктопное приложение для обучения методом интервальных повторений.  
Аналог Anki — создавай колоды карточек «вопрос → ответ» и повторяй по расписанию.

---

## Возможности

- Создание колод и карточек вручную через GUI
- Импорт карточек из CSV-файлов (UTF-8 и Windows-1251)
- Режим повторения с упрощённым алгоритмом интервальных повторений (SM-2)
- Режим просмотра — листать карточки без влияния на расписание
- Хранение данных локально в SQLite, без интернета

## Стек

|Компонент|Решение|
|---|---|
|Язык|Python 3|
|GUI|Tkinter|
|База данных|SQLite (`data/cards.db`)|
|Импорт|Стандартная библиотека `csv`|

## Алгоритм SM-2

Используется упрощённая версия алгоритма SuperMemo 2.  
После каждого повторения пользователь выставляет оценку — интервал до следующего показа пересчитывается автоматически:

|Оценка|Интервал|
|---|---|
|Плохо|сброс до 1 часа|
|Нормально|без изменений|
|Хорошо|×2|
|Легко|×3|

Карточки с трудностями возвращаются быстро, хорошо усвоенные — показываются всё реже.

## Формат CSV для импорта

Разделитель — точка с запятой (`;`):

```csv
Что такое интеграл?;Площадь под кривой.
Что обозначает символ C?;Константу интегрирования.
```

Поддерживаемые кодировки: UTF-8, Windows-1251.
